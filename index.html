Module 1 : Fondations

C'est quoi une API ?

L'API (Application Programming Interface) est le pont qui permet à deux logiciels de communiquer. C'est le "menu" des fonctionnalités qu'un logiciel expose aux autres.

L'analogie du Restaurant

  • Vous (Le Client) : Make.com (Votre workflow).
  • Le Serveur (L'API) : Prend la commande et l'amène en cuisine.
  • La Cuisine (Le Serveur distant) : Les serveurs d'OpenAI ou de Slack.
  • Le Plat : La réponse renvoyée (ex: le texte généré).
// La Requête (Ce qu'on demande)
POST https://api.openai.com/v1/chat/completions
Authorization: Bearer sk-votrecle...

{ "model": "gpt-4", "messages": [...] }
Module 1 : Fondations

Le vocabulaire des API (HTTP Methods)

Quand Make parle à une API, il utilise un "verbe" pour indiquer son intention. C'est le standard mondial du web (CRUD).

GET

Lire / Récupérer

"Donne-moi les infos du client #123".

POST

Créer / Envoyer

"Crée un nouveau client avec ces données".

(Toujours utilisé pour parler à l'IA)

PUT / PATCH

Mettre à jour

"Modifie l'adresse du client #123".

DELETE

Supprimer

"Supprime le client #123 de la base".

Module 1 : Fondations

JSON : Le Langage des Machines

Texte Humain (Non structuré)

Impossible à traiter automatiquement pour un logiciel. Où est le nom ? Où est le prix ?

"Bonjour, je m'appelle Jean Dupont. Je voudrais annuler ma commande numéro 48299 qui m'a coûté 45 euros. Merci d'avance."

Format JSON (Structuré)

JavaScript Object Notation. Organisé en paires "Clé": "Valeur". Make peut lire chaque champ séparément.

{
  "client_nom": "Jean Dupont",
  "action": "annulation",
  "commande_id": 48299,
  "montant": 45
}
Module 1 : Fondations

Webhooks vs Polling

Comment l'automatisation sait-elle qu'un événement s'est produit (ex: un nouvel email) ? Il y a deux méthodes fondamentales.

Polling (Vérification périodique)

Make demande à l'application toutes les 15 minutes : "As-tu du nouveau ?". S'il n'y a rien, il a consommé de la ressource pour rien.

Make ➔ "Nouveau mail ?" ➔ Non
Make ➔ "Nouveau mail ?" ➔ Oui !

Webhook (Temps réel)

Make génère une URL unique (Boîte aux lettres). Dès qu'un mail arrive, l'outil externe pousse l'information vers cette URL. Instatané et économique.

(Attente passive...)
Gmail ➔ POST Donnée ➔ Make déclenché !

Make indique le type de chaque variable avec une petite icône. C'est vital pour ne pas envoyer du texte là où l'API attend un nombre !

Aa String

Chaîne de texte.

42
Boolean

Vrai ou Faux.

true / false
Array

Une liste. Impossible à mapper directement dans un texte !

Module 3 : Deep Dive Make

Filtres et Routeurs

Le Filtre (La Douane)

Il se place sur la ligne. Il empêche la donnée de passer si une condition n'est pas remplie.

Ex: Continuer SEULEMENT SI "Urgence" = "Haute"

Le Routeur (L'Aiguillage)

Divise le workflow en plusieurs chemins parallèles. Indispensable pour créer de la logique conditionnelle complète (If/Else).

Module 3 : Deep Dive Make (Niveau Pro)

Itérateurs et Agrégateurs

Comment gérer des listes de données (Arrays) ? Un module qui attend du texte ne peut pas lire une liste entière d'un coup.

L'Itérateur (Éclater)

Prend un tableau (Array) et crée une exécution séparée pour chaque élément à l'intérieur.

Entrée : [Mail A, Mail B]
➔ Bundle 1 : Mail A
➔ Bundle 2 : Mail B

L'Agrégateur (Regrouper)

L'inverse exact. Attend que toutes les exécutions individuelles soient passées pour les regrouper dans un seul nouveau tableau (Array).

Entrée : Ligne 1, Ligne 2
➔ Sortie : [Ligne 1, Ligne 2]
Module 3 : Deep Dive Make

La Gestion des Erreurs (Directives)

Que se passe-t-il si l'API OpenAI est en panne ? Par défaut, Make désactive le scénario entier après 3 erreurs. Pour éviter ça, on accroche une "Error Route" sous un module.

Resume

Remplace la donnée par une valeur "Fallback" (ex: "Erreur IA") et continue le workflow.

Ignore

Arrête silencieusement l'exécution de cette branche, sans mettre le scénario entier en pause.

Break

Stocke la donnée et réessaie automatiquement (ex: dans 15 minutes, 3 fois max) avant d'échouer.

Module 4 : Intégration OpenAI

System Prompt vs User Prompt

Le System Prompt

C'est la directive fondamentale. Il définit le rôle, les règles strictes et le format de sortie de l'IA. Il est codé en dur.

"Tu es un expert en SAV. Ton rôle est d'analyser le ton de l'email client. Réponds uniquement par POSITIF, NEUTRE, ou NEGATIF."

Le User Prompt

C'est la donnée entrante dynamique à traiter. C'est ici que l'on va "mapper" les variables provenant des modules précédents.

"Voici l'email à analyser :
{{1.text_content}}"
Module 4 : Intégration OpenAI

La gestion du Contexte (Les Tokens)

C'est quoi un Token ?

L'IA ne lit pas des mots, elle lit des Tokens. (Environ 1 mot = 1,3 tokens en français). C'est l'unité de facturation.

L'Amnésie de l'API (Stateless)

Contrairement à l'interface ChatGPT qui "se souvient" de la discussion en cours, l'API est amnésique. À chaque nouvelle requête HTTP, l'IA repart de zéro.
Si vous voulez faire un Chatbot, vous devez sauvegarder l'historique et le ré-injecter en entier dans le prompt à chaque fois.

Concept Critique

Forcer le Format JSON

Ce qu'il ne faut PAS faire

Demander un JSON dans le prompt texte sans activer l'option de l'API. L'IA risque d'ajouter du texte conversationnel.

Voici le JSON :
```json
{ "nom": "Jean" }
```
J'espère que ça vous aide !
LA METHODE PRO
JSON Object Mode

Activez Response Format: JSON Object. Et ajoutez la phrase magique dans le System Prompt :

System: "Output ONLY valid JSON matching this structure: { 'nom': string }. No conversational text. No markdown."

Module 6 : Mise en Production

Debugging : L'Onglet Historique

Un scénario marche parfaitement en test, mais plante à 3h du matin en production. Pour comprendre pourquoi, allez dans l'onglet History.

  • Inspectez les "Bundles" pour voir la data entrante exacte.
  • Si erreur 400 (Bad Request) : Le format de votre donnée est mauvais.
  • Si erreur 500 : Le serveur en face (OpenAI) a crashé.

Cas Classique : Timeout

L'API d'OpenAI peut mettre 40 secondes à répondre. Make, par défaut, coupe la connexion après 40s (Timeout HTTP).

Solution : N'utilisez pas GPT-4o classique pour des tâches simples, passez sur mini (réponse en 1s).
